# OpenStreetMap - Sistema de mapa FTTH

Mapa georreferenciado de rede FTTH (OLTs, CTOs, CEOs, postes, torres, clientes e cabos)
usando **Vue 3 + Vite + Leaflet + OpenStreetMap**.

## Rodar o projeto

```bash
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Build de produção

```bash
npm run build
```
